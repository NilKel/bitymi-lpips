# BITYMI · spatial LPIPS heatmaps

Split-slider viewer for the **worst test views per scene** of the BITYMI production
checkpoints (`aftp_shres`, beta_scaled kernel): ground truth · render · per-pixel LPIPS.

Live: https://nilkel.github.io/bitymi-lpips/

**What the heatmap is.** LPIPS (VGG, v0.1, the repo's `lpipsPyTorch`) is a spatial mean
over linearly-weighted per-layer feature distances. Dropping that final mean and
bilinearly upsampling each layer's map to the image gives a per-pixel map whose mean
*is* the reported LPIPS (self-checked to 1e-7 per view). Inputs follow the repo /
3DGS `metrics.py` convention ([0,1] tensors), so scene means reproduce the numbers in
`docs/BITYMI_RESULTS_3D_SH_RES.md` up to the 8-bit PNG round-trip of the saved renders.

**Colour scale** is fixed across scenes (0 → `vmax` in `data/manifest.json`, default 1.0)
so heatmaps are comparable; hover to read the exact value.

**Generated by** `nest-splatting/scripts/lpips_heatmaps.py` from the renders that
`scripts/benchmark_baked.py --skip_bake` writes to `<ckpt>/baked_atlas/renders/sh_atlas/`.
Per scene the 3 worst views are exported (`data/<ds>_<scene>/<view>/`); `manifest.json`
carries the full per-view LPIPS/PSNR table.
